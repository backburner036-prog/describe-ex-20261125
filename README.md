This is an entry for the make.fun bounty **"Describe Your Ex in One Word"**: describe an ex in exactly one word, and let the judges pick the funniest verdict. My word is **Recalled** — my ex is like a defective product the factory had to recall: do not use, dangerous, return it. One word, no caption needed, and everyone who has ever dealt with a product recall gets the joke instantly.

> **Recalled**

## Run it

```bash
python3 main.py
```

Running `main.py` writes the word to `/output/entry.txt`. The entry is validated first (1–111 UTF-8 characters, no surrounding whitespace, no newlines) and the write is round-trip checked: the file is read back and must match exactly.
